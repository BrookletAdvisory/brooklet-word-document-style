# Brooklet Word Document Style

Standard `.docx` formatting for all Brooklet Advisory documents. Defines the house style — typography, layout, and Word-native automatic numbering — across three format lanes.

## Purpose

Every Brooklet Word output must feel: **clean, concise, professional, commercially sensible, and easy to review in Word.**

This skill:
1. Routes the document into the correct format lane (Agreement / Note / Memo)
2. Applies Candara 12pt typography with lane-appropriate structure
3. Enforces **Word-native automatic numbering** — never hard-coded numbers

## Three format lanes

| Lane | Use for | Key characteristics |
|------|---------|---------------------|
| **Agreement** | Services agreements, referral agreements, engagement letters | Formal clause-based, centered all-caps title, signature blocks, schedules |
| **Note** | Internal deal notes, candidate assessments, short working papers | Compact, direct, decision-useful; bullets and tables freely |
| **Memo** | Advisory memoranda, issue analysis, structured explanations | Analytical, organized; facts → analysis → recommendation |

## Automatic numbering (mandatory)

Numbers must be generated by Word's list engine via `numbering.xml`, **never** typed as literal text. This guarantees that inserting or deleting any list item in Microsoft Word auto-renumbers the rest.

| Purpose | Format | Restart behavior |
|---------|--------|-----------------|
| Parties | `(1)`, `(2)`, ... | Restarts at 1 each block |
| Background | `(A)`, `(B)`, ... | Restarts at A each block |
| Main clauses (multi-level) | `1.` (bold) → `1.1` → `(a)` | Lvl 0 continuous; Lvl 1/2 auto-restart on parent change |
| Schedule "No." column | `1.`, `2.`, ... | Restarts at 1 per schedule |

Full implementation pattern in `references/auto-numbering.py` — complete `python-docx` reference with abstract numbering XML definitions.
